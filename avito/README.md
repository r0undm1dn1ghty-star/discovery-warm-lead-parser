# Авито-сборщик (опционально)

Авито в Warm Lead Parser — режим **market-signal**: публичный поиск «Услуги» по нишевым запросам даёт живые цены конкурентов (полка 1К–12К, медиана ~3.5К). Это разведка рынка, а не лидген: карточки услуг пишут продавцы, не покупатели.

## Установка

```bash
pip install camoufox
python -m camoufox fetch
```

## Как работает

`avito_wlp.py` открывает публичный поиск `avito.ru/<region>/predlozheniya_uslug?q=<запрос>` в стелс-браузере Camoufox (Firefox со стелс-фингерпринтами). Антибот Авито сам рассасывается за 5–30 секунд — капчи не решаем. Результат — `avito_wlp_results.json` рядом со скриптом.

Движок подхватывает файл в режиме `--full`:

```bash
python warm_lead_parser.py --full chatbots
```

## Антибан-гигиена

- Пауза 3 сек между страницами, 5 сек между запросами — темп человека, листающего выдачу
- Никаких логинов: публичный поиск как руками
- Отдельный браузерный профиль, не ваш рабочий
- 1–2 запроса за прогон: разведка цен, а не обход каталога
