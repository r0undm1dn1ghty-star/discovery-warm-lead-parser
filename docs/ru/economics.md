# Экономика прогона: цена тёплого лида

## Зачем считать

Большинство лидген-инструментов заканчивают на «вот список». Вопрос бизнеса — «сколько мне стоил этот список и окупится ли он». Warm Lead Parser отвечает числом в каждом отчёте.

## Формула

```
Затраты прогона = 20 мин (разбор отчёта) + 15 мин × число тёплых (отклик каждому)
Стоимость в ₽  = Затраты в минутах / 60 × ваша ставка ₽/час
Цена лида      = Стоимость в ₽ / число тёплых
Окупаемость    = Средний чек / Цена лида
```

## Пример из реального прогона (07.09.2026)

- 28 постов собрано → 12 в нише → 1 тёплый
- Затраты: 20 + 15×1 = 35 мин ≈ **875₽** (ставка 1500₽/час)
- Цена тёплого лида: **875₽**
- Средний чек вашей услуги: подставьте свой в конфиг (по умолчанию 7000₽) → **окупаемость ×N** с первого закрывшего отклика

## Параметры в конфиге

| Параметр | Значение по умолчанию | Что значит |
|---|---|---|
| `my_hourly` | 1500 | Ваша целевая ставка ₽/час — подставьте свою |
| `avg_deal` | 7000 | Средний чек — для расчёта окупаемости |
| `response_time_min` | 15 | Минут на ручной отклик одному тёплому лиду |
| `report_per_run` | true | Писать экономику в каждый отчёт |

## Как читать экономику

- **Цена лида < 10% чека** — отличный прогон, откликайтесь на всех тёплых.
- **Цена лида 10–30% чека** — норм; подумайте о сужении ниши в конфиге (меньше мусора на входе).
- **Цена лида > 50% чека или ∞ (0 тёплых)** — два хода: добавить источники (Авито, Weblancer) или сменить нишу. Один пустой прогон — не сигнал; три подряд — сигнал.

## Честность чисел

- Время на «отклик» включает черновик сообщения, отправку и поиск контакта. Не включает созвоны и переговоры — это уже продажи, не лидген.
- Прогон автоматический: сбор+скоринг стоят ~0₽ вычислительно (запуск на вашем компьютере). Считается только ваше время разбора и отклика.
- Если тёплых 0 — отчёт пишет «∞ (0 тёплых)». Пустой прогон — тоже результат: рынок сегодня молчит.

## Экономика автопилота

При переходе на cron-прогон раз в час экономика меняется: сбор и скоринг становятся бесплатными, ваше время — только отклики. Формула остаётся, `report_per_run` пишет дайджест: «за день: N прогонов, M тёплых, цена лида X».
