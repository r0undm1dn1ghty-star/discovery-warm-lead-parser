# Отстройка: почему не «ещё один парсер»

## Рынок: кто ещё продаёт «ИИ ищет клиентов»

Рынок лидгена через ИИ в РФ уже сегментирован — мы честно описываем категории, без имён и ссылок на конкретных людей.

| Категория игрока | Что продаёт | Слабое место категории |
|---|---|---|
| **Эксперты-инфобизнес** (вебинары с банковскими площадками, программы 20–30К) | Промпт+JSON «вставь в Claude»: ТГ-чаты, маркетплейсы, форумы, VK; скоринг 0–100 | Промпт без движка: результат невоспроизводим, зависит от настроения модели. Закрытие через «менеджер перезвонит». Нет Авито, нет экономики. |
| **Маркетинговые агентства** (ТГ-мониторинг как услуга) | Python + Claude API + Telethon мониторят ТГ-чаты 24/7, дайджест | Логин-скрейпинг через Telethon = аккаунт-риск. Требует API-ключи Claude — не работает «из коробки». Только ТГ. |
| **SaaS-скрейперы** (западные, «любой сайт в 1 клик») | Подписка на скрейпинг | Вендорлок, подписка, РФ-платежи, нет скоринга под ИИ-нишу |
| **Фрилансеры-одиночки** (биржи, полка 2–10К) | «Сделаю парсер» руками | Часы работы, каждый запуск — новый проект |

## Наши четыре отличия

1. **Воспроизводимость.** Скрипт + конфиг вместо промпта. Сегодняшний прогон = завтрашний прогон. Балл объясняется строкой «почему».
2. **Экономика в каждом отчёте.** Цена тёплого лида, окупаемость ×N от вашего чека. Ни одна из категорий не считает деньги покупателя.
3. **Легальный периметр.** Только публичные страницы, ноль логинов, ноль API-ключей, ноль рассылок. У Telethon-агентов аккаунт-риск, у нас его нет по конструкции.
4. **Инструмент, а не услуга.** Один файл под вашу нишу: скачал, правишь конфиг текстом, прогоняешь. Без менеджеров, звонков и «оставьте заявку».

## Чего мы честно НЕ делаем (и почему это сила)

- Не парсим маркетплейсы-отзывы: для ниши «ИИ-агенты/боты» это нецелевой шум (там ищут товары, не подрядчиков).
- Не обещаем 100500 лидов: 20–30 постов за прогон, из них 0–3 тёплых. Честная арифметика.
- Не работаем без человека в контуре: отклик всегда пишете вы.

## Позиционирование одной строкой

**«Парсер, который не врёт»**: показывает ровно то, что нашёл, объясняет каждый балл и считает ваши деньги.
